# Consequential decisions

- Build original stdlib model rather than fork framework/browser infrastructure. No
  runtime install; smaller auditable scope, explicitly weaker than conformance evidence.
- Treat source standards/tests as references; freeze32 independently reasoned cases
  before code. Evaluator never reads expected labels. No upstream code copied.
- Use strict canonical DNS origins rather than pretend urllib equals browser URL parsing.
  Unsupported features retain unknown results; null marker never grants private intent.
- Supplied synthetic response headers model exact/reflection/wildcard policies. No server
  middleware header generator is needed to demonstrate the paired contrast; input facts
  remain visible instead of adding framework integration. This refines the plan diagram.
- All transactions declared cross-origin with no cache/redirect. Credentials are a mode,
  not evidence cookies were sent. Actual4xx/5xx readability differs from preflight2xx.
- Private allowlist intent is independent from protocol visibility; public wildcard control
  can be readable while outside private intent. Do not conflate them in vulnerability rates.
- Fresh reports and complete validation before output; partial new files on local I/O failure
  are explicit failures. No existing files overwritten or live targets contacted.
- ECC review performed by implementer; disclose this limit and require owner review before
  any separately authorized publication. No native-plugin/independent-review claim.
